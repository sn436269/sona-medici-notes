001. 這份研究計畫的核心問題，應如何用一句話說清楚？

  1. 追問私人財富如何取得公共意義，以及何時與政治認可相連
  2. 證明宗教捐贈是美第奇政治統治的主要原因
  3. 依藝術風格為兩代贊助人的審美成就排名
  4. 以銀行規模解釋文藝復興藝術的整體發展

合適答案：A

核心是追問十五世紀美第奇的私人財富，如何透過宗教、藝術與空間活動取得公共意義，以及這些意義在何種條件下與政治領導的認可相連。研究不是預先證明藝術能統治城市，而要逐案檢驗參與者、接收條件與政治解釋的證據界線。

  1. 私人財富如何取得公共意義
  2. 政治認可是待檢驗的關係
  3. 以具體案例限制結論

八頁研究計畫，第 3–4 頁；口試閱讀指南〈優先練答的四個研究問題〉。

002. 計畫的兩個核心案例與一個輔助案例，分別是什麼？

  1. 聖馬可與畫家赴羅馬為核心，美第奇宮為輔助
  2. 聖馬可與美第奇宮為核心，赴羅馬為補充
  3. 美第奇宮與陵寢為核心，聖馬可為補充
  4. 兩代全部收藏為核心，教宗時期作主要比較

合適答案：A

核心案例是老科西莫的聖馬可贊助，以及羅倫佐與畫家赴羅馬參與西斯汀側牆工程的關係；美第奇宮的建築、收藏與使用情境屬輔助案例。這個層級使研究能集中取得材料，也避免把家族所有收藏、建築與十六世紀活動一併納入。

  1. 聖馬可是第一核心案例
  2. 赴羅馬委託關係是第二核心案例
  3. 美第奇宮保持輔助地位

研究計畫第 6 頁，3.3〈研究材料與案例範圍〉；閱讀指南〈若材料不足，如何收斂研究〉。

003. 為什麼研究不宜直接寫成『美第奇利用藝術統治佛羅倫斯』？

  1. 這會預設政治目的、運作機制與統治效果都已成立
  2. 這會使研究過度依賴美學而忽略政治制度
  3. 這會要求先證明家族具有正式公爵爵位
  4. 這會使宗教文獻失去作為史料的資格

合適答案：A

這句話把政治目的、運作機制與統治效果都當作已知，容易讓所有贊助成為同一種宣傳。計畫需要先確認誰出資、誰委託、誰使用，再檢查公共聲望與政治認可的聯繫；宗教奉獻也可能同時具有虔誠、家族紀念與知識公益等意義。

  1. 避免預設單一政治目的
  2. 拆開活動、意義與效果
  3. 容納宗教及公益等多重功能

研究計畫第 3 頁，2.4〈研究回顧與研究缺口〉；Paoletti（1995），頁 19–36。

  2. 把不確定性轉成可研究的問題
  3. 依材料調整章節和比較規模

009. 計畫中的『宗教正當性』與『政治領導認可』，需要如何分開？

  1. 前者是修士的信仰，後者是贊助者公開表達的信仰
  2. 前者由捐款金額衡量，後者由宗教圖像數量衡量
  3. 前者證明財富來源合法，後者證明城市不再有反對聲音
  4. 前者涉及宗教規範評價，後者涉及特定群體對政治權力的接受

合適答案：D

宗教正當性涉及財富使用、虔誠、救贖與宗教規範的評價；政治領導認可則涉及特定人群對美第奇權力的支持或接受。捐贈得到宗教讚譽，並不自動證明政治支持；必須辨認評價者、語境及可見的政治行動，才能討論兩者是否相連。

  1. 宗教評價與政治支持不是同一命題
  2. 辨認發言者與評價對象
  3. 另找政治接受的具體材料

研究計畫第 1、3–4 頁；de Roover（1963），頁 10–14、410 註 19；閱讀指南〈如何證明聲望導致政治認可〉。

概念與比較

011. Magnificence 在 Rubin 的討論中，至少需要區分哪三層意思？

  1. 藝術品的價格、收藏總量，以及建築的完成數量
  2. 正式爵位、教會身分，以及國際外交地位
  3. 合宜支出的德性、社會稱謂，以及後世人物形象
  4. 私人慷慨、公共財政，以及城市法律效力

合適答案：C

第一層是大規模且合宜支出的德性，第二層是對有地位公民的社會稱謂，第三層是經敘述與頌揚形成的羅倫佐形象。三層互有關係，但不能混用；研究必須查誰在何時、何種文類中使用這個詞，才能判斷它是在描述行動還是塑造聲譽。

  1. 德性及支出的合宜性
  2. 社會稱謂與使用語境
  3. 後世人物形象的塑造

Rubin（1995），頁 37–39、45–47；閱讀指南〈Magnificence 是什麼〉。

012. 為什麼不能把 Magnificence 直接翻成『奢侈』或當作公爵爵位？

  1. 它主要指個人審美卓越，因此可用作藝術成就排名
  2. 它是共和城市授與最高領袖的制度性職稱
  3. 它含有倫理與稱譽意義，並非單純消費或正式爵位
  4. 它可由贊助支出大小判斷，不必另查使用語境

合適答案：C

奢侈容易只強調昂貴消費，忽略合宜支出、公共責任與榮譽的倫理判斷；公爵則是另一種正式政治身分。羅倫佐的『豪華者』稱號不能替代制度史查證，也不能單憑稱號推定每項贊助都成功增加聲望，仍須檢查當時評價與具體行動。

  1. 概念包含道德評價
  2. 稱號與正式爵位須分辨
  3. 稱譽不是贊助效果的直接證據

Rubin（1995），頁 37–49；研究計畫第 2–3 頁，2.3。

013. 為何不能將老科西莫歸為『虔誠』，將羅倫佐歸為『政治』？

  1. 兩代都可能兼有宗教及政治功能，選定案例不足代表全部活動
  2. 科西莫的宗教活動較多，因此可先排除其政治考量
  3. 羅倫佐善於外交，因此宗教支出應歸為形象工程
  4. 以虔誠和政治分別代表兩代，能避免比較機構差異

合適答案：A

兩代的宗教、家族紀念、公共聲望與政治關係都可能交織，Magnificence 也不只屬於羅倫佐。兩個選定案例呈現不同重心，尚不足以代表人物的全部活動；要比較的是特定條件下功能如何組合，不能把世代史寫成由虔誠走向政治的階段論。

  1. 兩代皆可能兼有多重功能
  2. 區分案例重心與人物全貌
  3. 避免單向發展的預設

研究計畫第 5 頁〈比較歷史研究法〉；閱讀指南〈用 Paoletti 與 Rubin 建立比較與概念〉。

014. 計畫所說的『空間政治』，除了建築物本身還包括什麼？

  1. 作品、配置、動線、使用者與儀式共同呈現權力關係
  2. 由建築規模及裝飾費用，測量贊助者的政治權力
  3. 根據今日參觀路線，重現歷史觀眾的完整體驗
  4. 先辨認家族擁有的建築，再分析它的藝術風格

合適答案：A

它包括作品的位置、進入制度、觀看動線、使用者及宗教儀式如何共同呈現權力關係。研究不只描述建築大小或裝飾華麗，也要問哪些人能在何時進入、能看見何物、如何使用；有關記憶與認同的效果，再另用評價和接受材料檢驗。

  1. 分析制度、動線和使用者
  2. 把作品放回活動環境
  3. 分開權力呈現與實際接受

研究計畫第 5–6 頁〈空間分析法〉；Terry-Fritsch（2012），頁 237–248。

015. 聖馬可與西斯汀活動形式不同，應用哪些共同項目比較？

  1. 比較促成者、資源、參與者、對象及評價，同時保留制度差別
  2. 比較兩案的藝術品件數，以數量判定兩代文化影響
  3. 用相同建築類型重新選案，才可能進行任何比較
  4. 將宗教建築列為早期、畫家外交列為成熟階段

合適答案：A

可用促成或委託者、資源投入、參與者、接收對象、空間及活動方式、評價材料作共同欄位。聖馬可是長期建築與制度贊助，赴羅馬是特定工程中的聘用與移動；共同欄位使比較可行，但仍須保留時間尺度與機構性質的差別。

  1. 使用相同的比較欄位
  2. 保留活動和制度的差別
  3. 只比較有限功能而非全面優劣

研究計畫第 5 頁；閱讀指南〈比較案例前先整理證據〉的兩案例比較表。

016. 『公共／私人』的二分，為何不足以概括美第奇的贊助活動？

  1. 私人出資的活動屬私人領域，公款工程屬公共領域
  2. 家族能從機構活動受益，表示它具有實際所有權
  3. 公共機構的正式決策，可以排除個人的仲介影響
  4. 財源、決策、使用與受益常不重合，須逐項確認角色

合適答案：D

私人出資可能進入城市或宗教機構，公共工程也可能讓個人取得聲望，決策、財源與受益者未必重合。以羅倫佐為例，須區分私人委託、公共職務、仲介與鑑賞；再檢查實際權限和資源，避免只因家族受益，就把機構活動寫成私人控制。

  1. 財源、決策與受益可能分離
  2. 辨認機構及個人各自權限
  3. 避免由聲望受益倒推所有權

Kent（2004）閱讀入口及 2026-10-13 文獻精選；Paoletti（1995），頁 19–36。

017. 『城市／鄉間』如何補充對羅倫佐空間活動的理解？

  1. 城內共和約束與郊外表述條件不同，仍需逐項查證
  2. 城內空間主要服務政治，郊外空間主要服務私人生活
  3. 郊外別墅具有君主意象，足以證明羅倫佐已是君主

071. de Roover 所討論的教會法 usury，為何不能只理解為『利率特別高』？

  1. 它主要指超過市場平均的利率，因此可用帳目利率判定
  2. 它涉及教會法對 mutuum 取利及契約分類，不只指高利率
  3. 它指銀行家從宗教機構取得收益，與一般商業貸款不同
  4. 它是所有匯兌收入的共同名稱，重點在收益而非契約

合適答案：B

其問題與 mutuum 借貸取利及契約的宗教、法律分類有關，不只是現代語感中過高的利率。不同商業形式、收益與風險也影響當時的判斷；因此不能把美第奇所有金融收入一概稱為公認非法高利貸，必須先辨認具體業務及規範語境。

  1. usury 需放回教會法語境
  2. mutuum 與其他契約須分辨
  3. 不能將全部銀行收入一概非法化

072. 匯兌契約、借貸與風險的區分，為何重要？

  2. 借貸與匯兌都產生收益，因此道德判斷應採同一標準
  3. 契約名稱主要用來規避禁令，不必研究其實際操作差別
  4. 當時判斷涉及契約形式和風險，不能將不同收益混為一類

合適答案：D

當時的神學與法律判斷會考慮契約形式及所承擔的風險，不能只看到收益就視為相同的借貸取利。研究要先確認金融操作，再討論其道德爭議；這不表示所有匯兌都沒有爭議，而是要求依具體安排和當時人的分類，避免現代概念的簡化。

  1. 收益相似不代表契約相同
  2. 風險影響當時的道德判斷
  3. 先辨業務，再討論宗教評價
