# SONA 語言日常｜每天六行

正式網站：https://sn436269.github.io/sona-medici-notes/language-study/

本地原始檔：/Users/sona/Desktop/Medici/語言

固定備份資料夾：/Users/sona/Desktop/Medici/語言/備份

只有三個主分頁：每天學習、單字庫、單字遊戲。

- 每天五個學習重點加一句完整句子，共六橫排，中英義與英文 KK 一起看；最新日期在最上面。
- 電腦一排、手機單字最多兩行，不需要左右拉。點單字另看 IPA 和文法。
- 義大利文按鈕直接播放 Lara Translate 自身語音服務產生的原音檔，保存在 audio/；不跳頁，不以裝置語音代替。英文按鈕使用裝置美式英文語音。
- 每日正式教材保存在 daily.json，歷史內容不隨前端日期輪播而消失。預備課程在 lessons.js，句子英文音標在 sentence-kk.json。
- 單字庫可搜尋、收藏、標記熟悉及自行新增；遊戲提供三個拼字相近的真正義大利文，可拖曳或點選。
- 原版瀏覽器個人紀錄 key 仍是 sona-language-journal-v1，保留既有收藏、自訂字、學習紀錄與筆記；個人資料不會上傳 GitHub。

每天台北時間 08:00 已設定 Codex 排程，檢查並發布當天教材及本地備份。背景更新需要 Mac 與 Codex 可執行；GitHub Pages 已發布內容的瀏覽和語音播放不需要電腦開著。

維護、發布、音檔產生及本地備份流程見 MAINTENANCE.md。語音服務若調整或限制會明確回報，不繞過限制，也不靜默更換供應商。
